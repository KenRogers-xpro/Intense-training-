## 2026-03-08 - Converting slider CSS background-images to HTML img elements
**Learning:** Pure CSS background-images bypass browser pre-parsers, delaying their load during page initialization. While lazy-loading offscreen background images is hard, converting them to HTML `<img>` elements allows using `loading="lazy"` and `decoding="async"` natively on off-screen slide images, while the first active slide gets `fetchpriority="high"`. This dramatically improves Largest Contentful Paint (LCP) and reduces initial network bandwidth consumption on heavy landing pages.
**Action:** Always inspect slider/carousel components for `background-image` properties. Move them to HTML `<img>` tags, utilizing eager high-priority loading for the first slide and lazy async loading for subsequent slides to achieve optimal loading characteristics.
