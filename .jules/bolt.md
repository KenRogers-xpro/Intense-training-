## 2025-03-06 - CSS Background Images vs HTML Image Elements for Carousels
**Learning:** CSS background-images are inherently difficult to optimize. Browsers eagerly download background-images declared in CSS, which blocks initial page loading and ruins Largest Contentful Paint (LCP) scores. Furthermore, standard attributes like `loading="lazy"`, `fetchpriority="high"`, and `decoding="async"` cannot be applied to background-images in CSS.
**Action:** Always convert carousel background-images to actual HTML `<img>` elements. For the initial visible slide, load it eagerly (omit `loading="lazy"`) with `fetchpriority="high"` and `decoding="async"` to optimize and protect LCP. For all subsequent offscreen slides, defer their loading with `loading="lazy"` and `decoding="async"` to minimize initial bundle loading time and CPU/network contention. Style the inner `<img>` tags with `object-fit: cover` and `border-radius: inherit` to perfectly replicate CSS cover/contain background behaviors.
