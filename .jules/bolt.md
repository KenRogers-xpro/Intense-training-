## 2025-02-15 - Optimizing Static Page Image Loading Strategy
**Learning:** In purely static multi-project web workspaces lacking sophisticated frameworks or asset pipelines, utilizing CSS background-images for carousel-style or critical content elements prevents proper asset optimization. Converting these CSS background-images to HTML `<img>` elements allows the use of modern performance hints: loading above-the-fold elements eagerly (using `fetchpriority="high"`) while lazily loading below-the-fold content (using `loading="lazy"` and `decoding="async"`). This protects Largest Contentful Paint (LCP) and defers non-critical asset payloads.
**Action:** Always inspect CSS background properties for layout/critical images. Convert them to semantic `<img>` tags and apply optimal performance-oriented loading attributes based on whether they are above or below the fold.
