## 2024-07-18 - Deferring Below-The-Fold Images inside Carousels
**Learning:** In static pages, using CSS `background-image` prevents browser-level optimization such as lazy-loading or asynchronous decoding. Converting these background images into HTML `<img>` elements allows using `loading="lazy"` and `decoding="async"` for below-the-fold/hidden carousel slides, while eagerly loading and raising fetch priority for the main hero image and the first slide. This reduces the initial page load time and network payload significantly without affecting above-the-fold LCP.
**Action:** Always prefer HTML `<img>` with native `loading` and `decoding` attributes over CSS `background-image` for carousels and lists, ensuring only initially offscreen/below-the-fold assets are deferred.
