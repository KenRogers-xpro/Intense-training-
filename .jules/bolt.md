## 2025-02-15 - Carousel CSS Background-Image Optimization
**Learning:** Using CSS `background-image` for sliders/carousels prevents browsers from optimizing asset loading. It forces all high-resolution images to load eagerly and synchronously, negatively impacting Largest Contentful Paint (LCP) and initial page load times. By converting these to semantic HTML `<img>` elements, we can utilize native browser optimization APIs: `fetchpriority="high"` for the active slide (LCP element) and `loading="lazy"` combined with `decoding="async"` for subsequent slides. This defers the load of off-screen slides while prioritizing the visible hero slide.
**Action:** Inspect carousel structures and avoid using CSS `background-image` for high-resolution slide backgrounds. Instead, use HTML `<img>` elements styled with `object-fit: cover` and control their loading priorities using native HTML attributes.
