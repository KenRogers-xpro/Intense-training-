## 2026-07-14 - Deferring Image Loading via HTML img vs CSS background-image
**Learning:** CSS `background-image` properties eagerly download image resources on DOM construction regardless of whether the elements are visible, below the fold, or part of inactive slider/carousel slides. Converting background-images to inline HTML `<img>` elements with `loading="lazy"` and `decoding="async"` successfully defers image fetching until they are about to enter the viewport, substantially reducing initial page payload size, avoiding blocking the main thread, and accelerating First Contentful Paint (FCP).
**Action:** When designing carousels, sliders, or below-the-fold content blocks with images, always prefer HTML `<img>` tags styled with `object-fit` and configured with `loading="lazy"` and `decoding="async"` over CSS `background-image` url references.
